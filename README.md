# 🏓 Pong Web

Classic Pong game built with HTML5 Canvas and vanilla JavaScript.

## Features
- 1 Player vs AI mode
- 2 Player local multiplayer
- Progressive AI difficulty (gets smarter as score increases)
- Particle trail effects on ball
- Score tracking — first to 7 wins
- Dashed center line and retro styling
- Sound effect simulation via Web Audio API

## Controls
### 1 Player
| Key | Action |
|-----|--------|
| W / S or ↑ ↓ | Move paddle |

### 2 Players
| Player | Keys |
|--------|------|
| Left | W / S |
| Right | ↑ / ↓ |

## Tech Stack
- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- Web Audio API (beep sounds)
